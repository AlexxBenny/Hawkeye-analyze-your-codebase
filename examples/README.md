# Examples

Practical examples showing how to use Hawkeye in different scenarios.

## Files

| Example | What it demonstrates |
|---------|---------------------|
| `basic_analysis.py` | Programmatic API — analyze a project and query results |
| `ci_check.py` | CI/CD integration — fail builds on architecture violations |
| `symbol_impact.py` | Symbol-level impact analysis — blast radius before refactoring |
| `sample_project/` | A tiny Python project to run examples against |

## Running

```bash
# From the Hawkeye root directory:
python examples/basic_analysis.py
python examples/ci_check.py
python examples/symbol_impact.py
```
